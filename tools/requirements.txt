# Required for tools/validate.py schema validation. This was previously
# missing from this file despite validate.py depending on it -- validate.py
# has a fallback path for when it's absent, but that fallback only checks
# for missing required fields and silently skips ALL pattern validation
# (code format, timezone format, hours format, etc). That's not a safe
# default for a data-integrity tool: an environment that just runs
# `pip install -r requirements.txt` (as the README's Quick Start instructs)
# would get validation that looks like it passed but wasn't actually
# checking most of what schema.json defines. Making it a hard requirement
# here instead of leaving it optional.
