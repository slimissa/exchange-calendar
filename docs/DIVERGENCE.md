This file is regenerated automatically every Monday at 08:00 UTC by the Divergence workflow (`.github/workflows/divergence.yml`), which opens a pull request when it changes. Manual edits will be overwritten; record verdicts in `docs/divergence_triage.json` instead.

Reference libraries: `exchange_calendars` 4.13.2, `pandas_market_calendars` 5.5.0. PMC is `pandas_market_calendars`, EC is `exchange_calendars`.

## How to read this

- Years requested: 2024 to 2026. The registry only has data inside each exchange's `generation_range`, so the registry is compared for 2024, 2025, 2026.
- For the registry, a trading day is a date that is not one of the exchange's `weekend_days` and not a `closed` holiday or ad-hoc closure. `early_close` and `delayed_open` days are trading days, so half days are not disagreements.
- Only regular working days are compared. A date on the exchange's `weekend_days` is skipped for all three sources, because the libraries model one-off weekend sessions (Budget Day, Muhurat, make-up Saturdays) that the registry does not and that differ between library versions.
- Registry, PMC and EC columns are trading days summed over the registry years above. `n/a` means the registry has no data; `No reference data` means that library does not know the exchange. A trailing `*` means the library was missing in some of those years.
- Agreement is trading days on which every available source agrees, divided by that count plus the disagreeing days. Days all sources agree are closed (weekends, shared holidays) are not counted. It is `n/a` when neither library has data.
- PMC and EC are not independent. PMC serves 46 of the exchanges that both libraries cover straight from `exchange_calendars` (its mirror calendars), so for those the PMC and EC columns are one source counted twice. PMC has its own implementation for XBOM, XNSE. Effectively the registry is being compared against one reference for the rest.
- A disagreement says nothing about which source is right. Nothing below has been checked against the exchange's own calendar unless stated.

## Session Times

Open time, close time, half-day status and intraday break, compared between the registry and the two reference libraries. Generated from `python3 tools/divergence_test.py --mode sessions --exchanges XASX,XHKG,XLON,XNAS,XNYS,XTKS --year 1990-2026`.

- Times are exchange-local `HH:MM`. The libraries publish UTC timestamps; each is converted with the exchange's IANA timezone, per date, so DST changes are handled.
- Open, close, half-day and break are compared only on days all sources trade. A day one source lacks is a trading-day disagreement, counted in the first column and not again in the others.
- Registry: the regular session, with `early_close_time` and `delayed_open_time` applied on those dates; a half day is a date with status `early_close`. Libraries: a half day is a close earlier than that library's usual close in the same calendar year.
- A break (Tokyo's and Hong Kong's lunch break) is part of one session. It is compared as a single `HH:MM-HH:MM` value and is `none` for exchanges without one. A break that ends at or after the day's close is no break, for every source: on a half day that closes before the lunch break ends, `pandas_market_calendars` reports a clipped break and `exchange_calendars` reports none.
- Regular hours can change over time. The registry stores them as a dated list where they did (Tokyo's close moved from 15:00 to 15:30 on 2024-11-05, Hong Kong's open from 10:00 to 09:30 on 2011-03-07), and each date is compared against the hours in force that day.
- A half-day mismatch normally appears with a close mismatch on the same date, so the two columns are not independent.
- Years: the registry only has data inside each exchange's `generation_range`, so only years where the registry and a library both have data are counted. PMC and EC are not independent for exchanges PMC mirrors from EC, so agreement with both is agreement with one reference.
